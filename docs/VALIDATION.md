# 验证范围

## 发布副本离线测试

2026-11-13，在 Windows、Python 3.13.12 环境下运行：

```bash
python tools/run_tests.py
```

369项通过，0失败、0错误、0跳过。测试运行器记录总耗时约14.2秒；这个时间不是机器人完成任务的用时，也不是视觉API延迟。

覆盖任务状态转换、超时与停止、脉冲执行状态、路线参数、串口替身、相机新帧约束、API响应解析、本地音频文件校验和几何匹配。测试中的音频是临时生成的静音文件，图像是合成图案，API与串口使用替身。

整理时的首轮检查发现两类发布耦合：两项厂家驱动补丁测试依赖未公开的驱动，另一个路线测试写死了旧距离。发布副本移除前者，并让路线测试读取当前参数；没有改动原比赛工程，也没有为了测试改变路线距离。

入口检查还修正了示例命令，并去掉模拟结束阶段对真实音频清单的依赖，新增无音频情况下的回归测试。真实模式仍需准备和校验本地音频；没有用空白音频代替现场语音。

## 入口检查与打包

发布检查覆盖ROS状态机的正常场景与目标丢失场景，以及定时路线的计划预览与离线模拟。目标丢失场景预期返回失败，不把停止执行当成检查异常。

打包流程扫描公开文件中的已知私人凭据、常见令牌格式、私人路径、受限版权声明、非公开资源及失效文档链接；随后检查ZIP校验和、逐文件哈希与解压后测试。扫描结果和详细运行日志留在本地，不随包分发。自动扫描不等于穷尽所有秘密或第三方权利问题。

## 没有验证的部分

- 没有连接机器人、打开真实串口、播放实际播报或调用付费API。
- 没有构建catkin工作空间，也没有验证目标ROS发行版及其Python绑定。
- 没有测试真实相机、光照、遮挡、定位精度、路程到位、实际出弹或命中。
- 没有用官方题卡评估发布副本的准确率，也没有把合成图测试算成模型实测。
- 没有独立核验比赛成绩或完成完整的权属审查。

离线通过只说明本副本的受测软件行为符合测试预期。资源、环境、参数和物理结果仍需分别核对。
